## Structured inventory

- **Headings / topics:** "תחום וטווח למול כלל ההתאמה" (section heading). Topics: the relationship between domain, range and the rule of correspondence ("כלל ההתאמה"), and partial ("חלקיים") domains.
- **Definitions / concepts:**
  - The domain is described as the "questions" the function is "ready to receive" ("מוכנה לקבל שאלות"), and the range as the "answers" it is "ready to give" ("מוכנה להשיב תשובות").
  - A function is not obliged to give every answer in the range: "הפונקציה איננה מחוייבת להשיב את כל התשובות שבטווח".
  - An expression is not a function when "קיים איבר בתחום שלא מותאם לו איבר אחד בטווח".
  - Domains and ranges need not be "כל הממשים" or "כל הטבעיים"; there are "טווחים ותחומים אחרים, חלקיים".
  - ★ "צמצום התחום של פונקציה – מביא לביטוי חדש שהוא פונקציה."
- **Commands / instructions introduced:** none
- **Algorithms / code blocks:** none
- **Trace tables:** none
- **Formulas:**
  - (א) `f : N → R`, `f (a) = a²`
  - (ב) `f : R → N`, `f(a) = a²`
  - (ג) `f : {0,1,2} → N`, `f(a) = a²`
  - (ד) `g : {מספרים אי-שליליים זוגיים} → N`, `g (a) = a`
  - Numbers used in the text: 2.5 and its square 6.25.
- **Worked examples (with the lecturer's solution steps):**
  - (א) Domain N, range R. *f* accepts whole numbers and is "ready" to answer with numbers that are not necessarily whole. In practice the rule gives only whole answers to whole questions. This is not a problem, because a function need not give every answer in the range.
  - (ב) Domain R, range N. This is a problem: 2.5 is a valid question, but its square 6.25 is not whole, so it is not in the range and not a valid answer. Therefore *f* is not a function: there is an element of the domain with no matching element in the range, and in fact infinitely many such elements.
  - (ג) and (ד) Partial domains, meaning fewer "questions" can be asked. They are still functions, because every element of the domain is matched to an element of the range. Conclusion (★): restricting the domain of a function gives a new expression that is a function.
- **Questions / exercises (verbatim, with numbers):** none

- **Lecturer's solution method / emphasis:**
