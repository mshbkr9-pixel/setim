## Structured inventory
- **Headings / topics:** "פונקציות רציפות ובדידות" (continuous and discrete functions).
- **Definitions / concepts:** "כללי ההתאמה" (rules of correspondence): the rules that let us find the value of the functions for any given input; a simplistic phrasing of a function value as question/answer ("כששואלים את f את השאלה 3 מקבלים את התשובה 9"); continuous ("רציף") vs. discrete ("בדיד"); the hidden assumption in a continuous graph that "all the numbers" interest us; a discrete graph made of infinitely many separate, whole, non-negative points.
- **Commands / instructions introduced:** none
- **Algorithms / code blocks:** none
- **Trace tables:** none
- **Formulas:** f(a) = a²; g(a) = a (known as y=x); a=3; f(3) = 9; g(3) = 3.
- **Worked examples (with the lecturer's solution steps):** (1) for a=3: f(3) = 9 and g(3) = 3. (2) g as the number of mobile phones in a room relative to the number of people in the room: there are no 3.5 phones for 3.5 people; the number of people and of phones is discrete, not continuous; most points of the continuous graph are irrelevant; negative numbers of people or phones are meaningless. (3) f as the number of people who gave a "like" ("חיבוב") to a post over the minutes: time is continuous (one can check after a minute and a half or three and a quarter minutes) but the number of likes is discrete, so many points of the graph do not represent a real situation. Conclusion: in both cases the graph is discrete, made of separate whole non-negative points (graph 2).
- **Questions / exercises (verbatim, with numbers):** none
