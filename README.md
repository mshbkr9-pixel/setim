## קבצים
- **v11 — 40 שיפורי נוחות, עיצוב ונראות** (ענף `v11-improvements`). נכתב ישירות לתוך `index.template.html` (בלי סקריפט `add_v11.py`); רוב הקוד החדש יושב בקטע `/* ===== v11 ===== */` לפני קטע האתחול.
  - **אימון ורישום סט:** מסך אימון ממוקד בלי לשוניות (`.app.focus`), עורך סט עם ספרות גדולות וכפתור אחד, "פעם קודמת" בכל שורה, סוגי סט וחימום אוטומטי, מחשבון פלטות, הערה נעוצה, החלפת תרגיל, החלקה למחיקה ולמעבר בין תרגילים, גרירה לסידור, לוח מספרים משלנו (אופציונלי). אימון שנשכח פתוח נעצר אחרי 20 דקות ונסגר לבד (`woTick`, `woSweep`).
  - **מנוחה:** `Rest` עם ‎−15/+15 ודילוג, זמן מנוחה שנזכר לכל תרגיל, מסך מלא, צליל (`Snd`, Web Audio), מסך דלוק (`Wake`), ושכבת `Dock` מעל הלשוניות.
  - **היום:** ברכה, רצועת שבוע עם תאריכים וצבעים, טבעת יעד שבועי, רצף בשבועות עם שבוע אחד נסלח בחודש (`weekStreak`), קופסה ראשית שמשתנה לפי המצב, והבובה כדמות (`MASCOTS`, `mascot()`).
  - **חגיגות ויומן:** באנר שיא ברגע הסימון, מסך סיום מלא (`showFinish`), כרטיס שיתוף כתמונה (`drawShare`), 16 הישגים (`ACH`, דף `#ach`), לוח שנה בעיגולים עם תצוגת שנה, מפת שרירים, סיכומים, וגרף על ציר זמן אמיתי.
  - **מראה:** צבע לכל קבוצת שרירים (`--g-*`), שישה גדלי טקסט (`--fs-1..6`) וארבעה רדיוסים (`--r-s/m/l/xl`), ארבע ערכות צבע (`data-accent`), גופן כותרות עגול אופציונלי (`data-font="round"`), טקסט גדול (`data-big`). ההעדפות נשמרות במסמך חדש `prefs` (`S.prefs`), שמסתנכרן כמו השאר.
  - **זרימה ואמון:** ניווט שזוכר מיקום גלילה, גיליונות שנסגרים בכפתור "חזרה", חיפוש סלחני (`searchEx`), הוספה מרובה ליום, הגדרות עם מתגים, גיבוי לקובץ וייצוא CSV, פתיחה בשלוש שאלות (`showOnboarding` ← `autoFillWeek`), שורת מצב סנכרון, וניסוח בלשון רבים במקום לוכסנים.
  - **שכבות:** מסך הסיום והמנוחה במסך מלא יושבים ב-`#pop` (z-index 50). הגיליון, ה-toast ולוח המספרים מוגדרים מעליו (52–56, בסוף ה-CSS) כדי שגיליון שנפתח ממסך הסיום לא ייפתח מאחוריו. כפתור הסגירה של גיליון יושב מול הכותרת (בפינה השמאלית).
  - **ערכה בהירה:** צבעי הטקסט `--accent-t`, `--bad` ו-`--warn-t` כהים יותר שם, ונבדקו לניגודיות 4.5 בכל המסכים ובכל ארבע ערכות הצבע. צבע הספרה בעיגולי לוח השנה נבחר לפי הבהירות בפועל (`calTone`).
  - `parts/pool.js`: סינון ציוד ביתי (`HOME_EQ`) כש-`S.profile.place==='home'`.
- `fonts/` — הגופנים (Heebo, Frank Ruhl Libre, Rubik; עברית ולטינית, woff2) מאוחסנים אצלנו. אין יותר קריאה ל-Google Fonts, והאפליקציה נטענת עם הגופן הנכון גם בלי רשת.
- `make_icons.py` — מייצר את האייקונים ואת מסכי הפתיחה לאייפון. `python make_icons.py a|b|c` בוחר איזו אפשרות חיה (a טבעת עם ס, b עמודות, c משקולת; **כרגע c**). שלוש האפשרויות ב-`icons/options/`, עשרה מסכי פתיחה ב-`icons/splash/`, האייקונים של v10 ב-`icons/old/`.
- `add_v10.py` + `build.py` — **v10: שלוש לשוניות בלבד (היום · יומן · עוד)** ומקסימום כשלושה כפתורי פעולה במסך. "היום": רצועת השבוע, קופסה אחת עם טבעת התקדמות (סטים שבוצעו מתוך המתוכננים), כפתור "התחל אימון" ותפריט ⋯ אחד ליום; רשימת התרגילים בלי כפתורי מינוס (הסרה דרך ⋯ ← "סדר או הסר", או מתפריט התרגיל). "יומן": כרטיס סיכום שבועי אחד (לחיצה = גרפים ושיאים) + לוח שנה. "עוד": כרטיס פרופיל ושש קופסאות (תרגילים, תוכניות, המכון שלי, מדריכים, קלוריות, הגדרות); דף **הגדרות** חדש (`#settings`: טיימר, מראה, הדגמות, מעבר אוטומטי, התרגילים שלי, הוספה למסך הבית, שיתוף, כניסה/יציאה, גיבוי ושחזור כולל שבוע/אימונים קבועים/ימים). הפרופיל נשאר שם, גוף ומטרה בלבד. דף תרגיל: הפעולות רק בתפריט ⋯ (בלי שורת כפתורים כפולה); אימון מודרך: סיום אחד (בתיבת הסטופר) ובלי "הקודם/דלג" (הרצועה מנווטת). תוכניות: כפתור אחד "מלא את השבוע לפי התוכנית", ויום בתוכנית נפתח בגיליון. נמחק קוד מת (המתכנן השבועי הישן `week()`, `startChecklist`, `setsHint`). תוקן באג: ימי מנוחה ברצועת השבוע ובלוח השנה היו בלתי נראים (המחלקה `rest` התנגשה עם טיימר המנוחה; עכשיו `off`). **מעכשיו עורכים רק את `index.template.html` ומריצים `python build.py`.**
- `anim.js` — **הדגמות מונפשות לתרגילים (v8)**: דמות SVG ממופרקת (מבט צד/חזית) עם ציוד (מוט, משקולות, קטלבל, כבל, ספסל, מכונות), 240 "ארכיטיפי תנועה" וכללי מיפוי מזהה-תרגיל → ארכיטיפ (`EXANIM.RULES`). מכסה את כל 701 התרגילים; תרגיל מותאם אישית יכול לבחור הדגמה בעריכה (`e.anim`). השריר העובד זוהר בהתאם ל-`subOf`. בהגדרות אפשר לחזור לתמונות. העקרונות נלקחו מסקיל `anatomy` (גופים מלאים, ארבעה טונים, תנועה רגועה מבוססת זמן, עצירה מחוץ למסך ו-reduced-motion). `anim-preview.html` — דף פיתוח שמציג את כל הארכיטיפים (`?k=squat,ohp` לסינון); להרצה: `python -m http.server 8765` בתיקייה.
- `add_v9.py` — v9: **לוח שנה** בראש היומן (`calendar()`: חודשים אחורה/קדימה, ימים שבוצעו עם מספר תרגילים, ימים מתוכננים, מנוחה, סיכום חודשי), דף לכל תאריך (`#day-YYYY-MM-DD`: מה בוצע, עריכת סטים לכל תרגיל בתאריך דרך `#dayex-<date>-<id>`, הסרה עם ביטול, הוספת תרגיל לתאריך בעבר עם "סמן הכול כבוצע", שם לאימון), ולתאריכים עתידיים: התוכנית השבועית או **חריגה לתאריך אחד** (`S.days.map[date].plan`; `wkDay(i)` מחזיר את החריגה כשהיא בשבוע הנוכחי). `setsCard(e,{date})` רושם לכל תאריך, והרשומות נשמרות ממוינות לפי תאריך. תיקון: `loadLocal` לא נעצר יותר על ערך שאינו JSON (`gt:theme`).
- `add_v8.py` — v8: הדגמות במקום תמונות, מצב **"התחל אימון"** (`#workout`: סטופר, פס התקדמות, הדגמה, רישום סטים, מעבר אוטומטי לתרגיל הבא בסוף המנוחה, סיכום שנשמר ליומן עם משך), **התרגילים שלי** בהגדרות (`#myex`), תפריט ⋯ בדף תרגיל עם "הסר מהיום"/"החלף", פח במצב סידור. מצב האימון נשמר במפתח `wo`.
- `index.html` — הקובץ המפורסם. **לא לערוך ישירות**: נבנה ב-`python build.py` מ-`index.template.html` (ממשק, לוגיקה) + `parts/catalog.js` (יצרנים/מכשירים/ציוד) + `parts/pool.js` (מאגרי תרגילים לתוכניות) + `articles.js` (המדריכים).
- `index.v1.html`, `index.v4.html` — גרסאות קודמות (גיבוי). v7 הוסיפה טקסונומיית שרירים מפורטת (`SUBS`, 22 תת-קבוצות: חזה עליון/תחתון, לאטס, גב עליון/תחתון, שלוש הכתפיים, ביצפס/טריצפס/אמות, ארבע-ראשי/האמסטרינג/תאומים/מקרבים/כופפי ירך, ישבן, בטן/אלכסונים/ליבה) עם סיווג לפי שריר ראשי + שם התרגיל (`subsOf`); משמשת לסינון בספרייה, להרכבת יום מתת-שרירים ולסטטיסטיקה. v6 הוסיפה: כפתור סגירה בכל גיליון, הסרה עם ביטול בכל תרגיל, קטגוריית קליסטניקס ופעילויות בחוץ (רישום בדקות וק״מ), זרימת סוג יום ← בחירת תרגילים, אימונים קבועים (`routines`) וזיהוי סבב (`days`: תווית ותרגילים לכל תאריך אימון). הגרסה v5 מינימליסטית: 4 לשוניות (היום / יומן / תרגילים / עוד); "היום" = פס ימי השבוע + התרגילים של היום, לחיצה = רישום סטים.
- `add_*.py` — הסקריפטים שבנו את הגרסאות (PWA, חשבונות, UX, תוכנית שבועית). `icons/og.png` תמונת תצוגה מקדימה לשיתוף, `icons/qr.png` QR של הכתובת.
- `data/exercises.json` — 701 תרגילים (שמות בעברית ובאנגלית, שרירים, ציוד, הוראות, טיפים).
- `data/img-<group>.json` — תמונות התרגילים (320px WebP, base64) לפי קבוצת שרירים, נטענות לפי צורך.
- `img/` — תמונות המקור (512px) מ-RepDB. לא מתפרסמות, משמשות לבנייה בלבד.
- `build_data.py` — בונה את `data/exercises.json` מתוך מאגר RepDB + קובצי התרגום.
- `pack_images.py` — מקטין ואורז את התמונות לקובצי ה-JSON.
- `BRANDS_RESEARCH.md` — מחקר על יצרני מכשירי כושר והיבואנים שלהם בישראל.

## נתונים ושיתוף
- בקישור הציבורי יש הרשמה וכניסה (אימייל + סיסמה) מול PocketBase בשרת srv1809211 (`https://setim.2-24-161-2.sslip.io`). כל משתמש רואה רק את השורות שלו (כללי API של PocketBase). בלי התחברות הנתונים נשמרים במכשיר (localStorage); בהתחברות ראשונה הנתונים המקומיים עולים לחשבון.
- **השרת פעיל** (הותקן 2026-11-05): ממשק ניהול `https://setim.2-24-161-2.sslip.io/_/`, פרטי כניסה ב-`master_keys.env` (`SETIM_PB_*`). `server/pb_setup.sh` התקין את PocketBase בשרת מאחורי Caddy; `server/pb_schema.py` יוצר את הסכמה (`docs`: user, key, data); `server/mock_pb.py` שרת דמה לבדיקות מקומיות (האפליקציה פונה ל-127.0.0.1:8090 כשהיא רצה מ-localhost).
- `manifest.json`, `sw.js`, `icons/` — הופכים את הקישור הציבורי ל-PWA שמותקן במסך הבית.

- כל משתמש שנכנס עם חשבון Claude מקבל נתונים פרטיים משלו (`data/users/<id>/`).
- כדי שחברים יוכלו לשמור אימונים, יש לשתף את הקישור ברמת **Contributor** (לא Viewer).
- בלי חיבור, הנתונים נשמרים ב-localStorage של הדפדפן.

## הרכבת index.html מחדש
```
python build.py
```
הטמפלייט מכיל שלושה סמנים: `/*__CATALOG__*/` ← `parts/catalog.js`, `/*__POOL__*/` ← `parts/pool.js`, `/*__ARTICLES__*/` ← `articles.js`. הסקריפט מחליף אותם ושומר `index.html` (CRLF, כמו שאר הקבצים בעותק העבודה). סקריפטי `add_vN.py` משנים את הטמפלייט בלבד; אחריהם מריצים build.
