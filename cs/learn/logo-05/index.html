פרוצדורה: TO ... END, הגדרה מול קריאה

לתת שם לרצף פקודות; Commander ו־Edall ב־MSWLogo

מקור:חלון ה־Commander והכפתור Edall שפותח את העורך — שקף 4 (צילום 71). "מתן שם" ו"פרוצדורה ללא משתנים" — שקפים 7 ו־10 (צילומים 70, 69). "את הפרוצדורה כותבים במסך העורך שפותח כפתור Edall" — שקף 16 (צילום 67).· ודאות בפענוח המקור: גבוהה
המורה שלך

אהקדמה

מה לומדים

פרוצדורה היא רצף פקודות שקיבל שם. מגדירים אותה פעם אחת עם TO שם ... END, ואחר כך כותבים רק את השם — והצב מבצע את כל הפקודות.

למה זה חשוב

כך לא צריך להעתיק שוב ושוב את אותן פקודות. רוצים ריבוע בכמה מקומות? מגדירים SQUARE פעם אחת וקוראים לה כמה פעמים שצריך. חשוב להבחין: הגדרה רק שומרת את הפרוצדורה; קריאה מפעילה אותה.

בסוף השיעור תדעו
  • להגדיר פרוצדורה עם TO ... END
  • להבחין בין הגדרה (לא מציירת כלום) לבין קריאה (מבצעת)
  • לדעת מה כותבים איפה ב־MSWLogo: הגדרות בעורך (Edall), ופקודות לביצוע מיידי בשורת ה־Commander

במילון מושגים

פרוצדורה

רצף פקודות עם שם. כמו מילה חדשה שמלמדים את הצב.

הגדרה (TO ... END)

המקום שבו מלמדים את הצב את המילה החדשה: TO, השם, הפקודות, ובסוף END. ההגדרה לבדה לא מזיזה את הצב.

קריאה

כתיבת שם הפרוצדורה כפקודה. רק אז הצב מבצע את הפקודות שבהגדרה.

מתן שם

לקחת רצף פקודות ולתת לו שם. כך בשקפים: מ־REPEAT 4 [ ... ] אל TO SQUARE.

Commander

החלון הראשי של MSWLogo. בשורה התחתונה שלו כותבים פקודה ולוחצים Execute — והיא מתבצעת מיד.

Edall (העורך)

כפתור בחלון ה־Commander שפותח את חלון העורך (Editor). שם כותבים את ההגדרות TO ... END.

גהסבר ויזואלי

רמה: רגילהסבר חדש

מבנה ההגדרה:

  • שורה ראשונה: TO ושם הפרוצדורה (למשל TO SQUARE).
  • באמצע: הפקודות שהפרוצדורה מבצעת.
  • שורה אחרונה: END.

ב־MSWLogo כותבים את ההגדרה בחלון העורך, שנפתח בלחיצה על Edall. אחרי שהעורך נסגר הפרוצדורה שמורה — אבל על המסך לא קרה כלום.

כדי להפעיל אותה כותבים SQUARE בשורת הפקודה של ה־Commander ולוחצים Execute.

אפשר לקרוא לפרוצדורה גם מתוך פקודות אחרות — למשל בתוך REPEAT.

חומר מקור

שקף 4: חלון ה־Commander (כפתורים Halt, Trace, Pause, Status, Step, Reset, Execute, Edall). הכפתור Edall מוקף בעיגול, וחץ מוביל ממנו לחלון ה־Editor, ובו: to square / repeat 4 [ / fd 10 / rt 90 / ] / end.

חומר מקור

שקפים 7 ו־10: REPEAT 4 [ FD 10 RT 90 ] → (חץ "מתן שם") → TO SQUARE / REPEAT 4 [ / FD 10 / RT 90 / ] / END, עם הכיתוב "פרוצדורה ללא משתנים". התווית "שם" מצביעה על המילה SQUARE.

חומר מקור

"את הפרוצדורה כותבים במסך העורך שפותח כפתור Edall." (שקף 16)

ההתנסות

בעורך כבר מוגדרת הפרוצדורה TRIANGLE — אבל אין אף קריאה, ולכן המסך ריק. כתבו בשורת ה־Commander (או מתחת ל־END) לולאה שקוראת ל־TRIANGLE ארבע פעמים, עם RT 90 אחרי כל קריאה, כדי לקבל את ציור המטרה.

חסיכום והמשך

מה למדנו
  • TO שם ... END מגדירה פרוצדורה — ההגדרה לבדה לא מזיזה את הצב
  • כתיבת שם הפרוצדורה היא קריאה — רק אז הפקודות מתבצעות; אפשר לקרוא כמה פעמים, גם מתוך REPEAT
  • ב־MSWLogo: Edall פותח את העורך להגדרות; בשורת ה־Commander כותבים פקודות לביצוע מיידי

מושגים שכבר למדתם בקורס: 0. שיעורים שהושלמו: 0.

מה הלאה

SQUARE מציירת תמיד ריבוע שצלעו 10. בשיעור הבא נוסיף לה משתנה — :SIZE — ונצייר ריבוע בכל גודל.

לשיעור הבא: פרוצדורה עם פרמטר (:SIZE) ←→ לולאת REPEAT: ריבוע ומצולעים
