לולאת REPEAT: ריבוע ומצולעים

לחזור על פקודות n פעמים, ולפרש לולאה בתוך לולאה

מקור:הריבוע REPEAT 4 [ FD 10 RT 90 ] — שקפים 7 ו־10 (צילומים 70, 69). המשולש REPEAT 3 [ FD 100 LT 120 ], הלולאה בתוך לולאה והשלד לפירוש — שאלה 2 בדף המשימה (צילום 54). התוויות בשלד ריקות בדף; הפירוש שבשיעור נכתב כאן.· ודאות בפענוח המקור: גבוהה
המורה שלך

אהקדמה

מה לומדים

REPEAT n [ ... ] חוזרת n פעמים על הפקודות שבתוך הסוגריים המרובעים. כך מציירים ריבוע — ועוד הרבה צורות — בשורה אחת.

למה זה חשוב

ריבוע הוא 4 פעמים "צלע ופנייה". במקום לכתוב 8 שורות כותבים לולאה אחת. לולאה גם עוזרת לקרוא אלגוריתם: רואים מיד מה חוזר על עצמו.

בסוף השיעור תדעו
  • לכתוב ולקרוא לולאת REPEAT
  • לצייר ריבוע, משולש ומצולע משוכלל, ולבחור את זווית הפנייה
  • לפרש לולאה בתוך לולאה, גוש אחרי גוש, כמו בשלד שבדף המשימה

במילון מושגים

לולאה

הוראה שאומרת "חזור על זה כמה פעמים". כמו "הקף את המגרש 4 פעמים".

REPEAT

הלולאה של LOGO. REPEAT 4 [ FD 10 RT 90 ] = ארבע פעמים: קדימה 10, ימינה 90.

גוף הלולאה

הפקודות שבתוך הסוגריים המרובעים [ ] — מה שחוזר בכל סיבוב.

סיבוב

פעם אחת שבה מבצעים את כל גוף הלולאה.

מצולע משוכלל

צורה סגורה שכל הצלעות שלה שוות וכל הזוויות שלה שוות: משולש שווה צלעות, ריבוע, משושה...

לולאה מקוננת

לולאה בתוך הגוף של לולאה אחרת. הפנימית מתבצעת כולה בכל סיבוב של החיצונית.

גהסבר ויזואלי

רמה: רגילהסבר חדש

צורת הכתיבה: REPEAT מספר [ פקודות ]. אפשר לכתוב בשורה אחת, או כמו בשקפים: [ בסוף שורת ה־REPEAT, הגוף מוזח פנימה, ו־] בשורה נפרדת.

כדי לסגור מצולע הצב צריך להסתובב בסך הכול סיבוב שלם — 360 מעלות. לכן:

  • ריבוע: 4 פניות של 90 (4 × 90 = 360)
  • משולש שווה צלעות: 3 פניות של 120
  • משושה: 6 פניות של 60

בסוף מצולע כזה הצב חוזר בדיוק לנקודת ההתחלה, ופונה לכיוון שבו התחיל.

חומר מקור

הקופסה הראשונה בשקפים 7 ו־10: REPEAT 4 [ / FD 10 / RT 90 / ] — ריבוע שצלעו 10.

חומר מקור

דף המשימה, שאלה 2: "נתון אלגוריתם ושלד של תרשים. פרשו את האלגוריתם במילוי שיטתי של תוויות התרשים. (הערה : הפירוש לא במילים אלא בשרטוטים)". באלגוריתם יש לולאה בתוך לולאה: REPEAT 4 [ / REPEAT 3 [ / FD 100 / LT 120 / ] / PU / FD 150 / RT 90 / FD 50 / PD / ].

חסיכום והמשך

מה למדנו
  • REPEAT n [ ... ] מבצעת את הגוף n פעמים
  • מצולע משוכלל בעל n צלעות: n סיבובים של "צלע ופנייה של 360/n מעלות"
  • בלולאה מקוננת הפנימית מתבצעת כולה בכל סיבוב של החיצונית; מפרשים גוש אחרי גוש, מבפנים החוצה
