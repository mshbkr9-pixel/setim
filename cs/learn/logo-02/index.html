פקודות הצב: FD, BK, RT, LT

מיקום מול כיוון: מה זז ומה רק מסתובב

מקור:טבלת הפקודות והאזהרה "שתי פניות של 90 מעלות אינן שקולות לפקודת תנועה" — מהמחברת המעובדת (עמ׳ 3). FD, RT ו־LT מופיעות באלגוריתם של דף המשימה (צילום 54). BK אינה מופיעה בצילומים: היא פקודה רגילה של LOGO (MSWLogo) ושל הסימולטור.· ודאות בפענוח המקור: גבוהה
המורה שלך

אהקדמה

מה לומדים

נכיר את הצב של LOGO ואת ארבע פקודות התנועה שלו: FD (קדימה), BK (אחורה), RT (פנייה ימינה) ו־LT (פנייה שמאלה).

למה זה חשוב

כל ציור ב־LOGO בנוי מהפקודות האלה. כדי לקרוא אלגוריתם צריך לדעת בכל רגע שני דברים על הצב: איפה הוא עומד ולאן הוא פונה.

בסוף השיעור תדעו
  • לבצע בראש את FD, BK, RT ו־LT
  • להבחין בין המיקום של הצב לבין הכיוון שלו
  • לדעת את מצב הצב (מקום וכיוון) בסוף רצף פקודות

במילון מושגים

צב

החץ הקטן על המסך שמבצע את הפקודות. בכל מקום שהוא עובר הוא משאיר קו, כמו עט.

מיקום (x, y)

איפה הצב עומד. x = כמה צעדים ימינה מהאמצע (מספר שלילי = שמאלה). y = כמה צעדים למעלה (שלילי = למטה). בהתחלה הצב באמצע: (0, 0).

כיוון

לאן הצב פונה, במעלות, כמו מצפן: 0 = למעלה, 90 = ימינה, 180 = למטה, 270 = שמאלה. בהתחלה: 0.

מעלה (°)

יחידה למדידת סיבוב. סיבוב שלם = 360 מעלות, חצי סיבוב = 180, רבע סיבוב = 90.

FD / BK

קדימה / אחורה, מספר צעדים. הן משנות רק את המקום של הצב.

RT / LT

פנייה ימינה / שמאלה, מספר מעלות. הן משנות רק את הכיוון — הצב לא זז ממקומו.

גהסבר ויזואלי

רמה: רגילהסבר חדש

לצב יש מיקום וכיוון. בהתחלה הוא באמצע המסך, בנקודה (0, 0), ופונה למעלה (כיוון 0).

  • FD 50 — 50 צעדים קדימה, לכיוון שאליו הצב פונה עכשיו.
  • BK 50 — 50 צעדים אחורה, בלי להסתובב.
  • RT 90 — פנייה ימינה ב־90 מעלות (רבע סיבוב). הכיוון גדל ב־90.
  • LT 90 — פנייה שמאלה ב־90 מעלות. הכיוון קטן ב־90.

לכן FD 50 אחרי RT 90 מובילה ימינה, ו־FD 50 אחרי LT 90 מובילה שמאלה.

חומר מקור

דף המשימה "א.2 היכרות עם שפת לוגו (א) פעולות אלמנטריות" בנוי מהפקודות FD, RT ו־LT (וגם PU, PD ו־REPEAT, שנלמד בהמשך). למשל השורות: LT 90 / FD 50 / RT 90.

חסיכום והמשך

מה למדנו
  • לצב יש מיקום (x, y) וכיוון: 0 = למעלה, 90 = ימינה, 180 = למטה, 270 = שמאלה
