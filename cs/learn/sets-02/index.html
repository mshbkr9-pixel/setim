קבוצות מיוחדות: ℕ, ℝ, ℤ, ∅

הטבעיים, הממשיים, השלמים והקבוצה הריקה

מקור:עמוד 2: "קבוצות מיוחדות שיהיו שימושיות במסגרת קורס זה" (הכותרת והשורה של N נראות גם בצילום 42)· ודאות בפענוח המקור: גבוהה
המורה שלך

אהקדמה

מה לומדים

נכיר ארבע קבוצות שיש להן סימן קבוע, בסדר שבו הן מופיעות בדף: ℕ (הטבעיים), ℝ (הממשיים), ℤ (השלמים) ו־∅ (הקבוצה הריקה).

למה זה חשוב

כמעט כל כלל בקורס אומר מאיזה סוג המספרים: טבעיים, שלמים או ממשיים. במקום לכתוב את זה במילים, משתמשים בסימנים האלה.

בסוף השיעור תדעו
  • לזהות את הסימנים ℕ, ℝ, ℤ, ∅ ואת שמותיהם
  • לדעת ש־0 שייך ל־ℕ בקורס שלנו
  • לדעת ש־ℝ מכילה גם מספרים כמו 2\sqrt{2}2​ ו־π\piπ
  • להבחין בין הסימן ∅ לבין האות היוונית Φ

במילון מושגים

ℕ — המספרים הטבעיים

מספרי הספירה: 0, 1, 2, 3 וכן הלאה. בלי שברים ובלי מינוס. אצלנו בקורס גם 0 בפנים.

ℝ — המספרים הממשיים

כל המספרים שיש על ציר המספרים: גם שברים כמו 2.5, גם שליליים, וגם מספרים כמו 2\sqrt{2}2​ ו־π\piπ.

ℤ — המספרים השלמים

כל המספרים בלי שבר — חיוביים, שליליים ו־0: …, −2, −1, 0, 1, 2, …

∅ — הקבוצה הריקה

קופסה ריקה: קבוצה שאין בה אף איבר. כותבים אותה גם כך: {}.

ציר המספרים

קו ישר שעליו כל המספרים מסודרים לפי הגודל: השליליים משמאל ל־0, החיוביים מימין.

גהסבר ויזואלי

רמה: רגילהסבר חדש

ℕ = {0,1,2,3,…}\{0, 1, 2, 3, \ldots\}{0,1,2,3,…}. שימו לב: אצלנו בקורס 0 שייך ל־ℕ (יש ספרים שמתחילים מ־1).

ℝ = כל המספרים העשרוניים שעל ציר המספרים: רציונליים ואי־רציונליים, חיוביים ושליליים, למשל 2\sqrt{2}2​ ו־π\piπ.

ℤ = המספרים השלמים, חיוביים ושליליים (וגם 0).

∅ = הקבוצה הריקה, {}. הסימן הוא אות סקנדינבית — לא האות היוונית Φ.

בדפי הקורס הסימנים מודפסים כאותיות מודגשות: N, R, Z. בספרים רבים כותבים ℕ, ℝ, ℤ — זה אותו דבר.

חומר מקור

N — קבוצת המספרים הטבעיים (Natural): שלמים שאינם שליליים, כלומר: {0,1,2,3,…}\{0, 1, 2, 3, \ldots\}{0,1,2,3,…}. שימו לב כי אצלנו בקורס 0 שייך לקבוצה N.

חומר מקור

R — קבוצת המספרים הממשיים (Real): כל המספרים העשרוניים שעל ציר המספרים. שימו לב שיש בקבוצה R מספרים רציונאליים ואי־רציונאליים חיוביים ושליליים, 2\sqrt{2}2​, π\piπ, וכו׳.

חומר מקור

Z — קבוצת המספרים השלמים (Zahlen = "מספרים" בגרמנית): מספרים שלמים, הן חיוביים והן שליליים.

חומר מקור

∅ — הקבוצה הריקה: קבוצה שאין בה איברים, {}. שימו לב שהסימון של הקבוצה הריקה איננו האות היוונית פי Φ אלא אות סקנדינבית.

דהדגמה מפורקתהסבר חדש

לאילו קבוצות שייך כל מספר?

שלב 1 מתוך 6

7: מספר ספירה רגיל — שלם ולא שלילי. לכן 7 ב־ℕ. וכל מה שב־ℕ נמצא גם ב־ℤ וגם ב־ℝ.

ℕ = 7ℤ = 7ℝ = 7

ההתנסות

בתרשים שני עיגולים: ℕ ו־ℤ. מספר שנשאר מחוץ לשניהם נחשב "רק ב־ℝ". גררו כל מספר לאזור הנכון. שאלה למחשבה: האם יש מספר שצריך לשים ב־ℕ אבל לא ב־ℤ?

ושאלה לבדיקת ההבנה

התאמהרמה 1תרגיל חדשמקור:

התאימו כל סימן לקבוצה שהוא מסמן.

N\mathbb{N}N
Z\mathbb{Z}Z
R\mathbb{R}R
∅\emptyset∅

חסיכום והמשך

מה למדנו
  • ℕ = {0,1,2,3,…}\{0, 1, 2, 3, \ldots\}{0,1,2,3,…} — ובקורס שלנו 0 שייך ל־ℕ
  • ℤ = כל השלמים, חיוביים ושליליים
  • ℝ = כל המספרים שעל ציר המספרים, כולל 2\sqrt{2}2​ ו־π\piπ
  • ∅ = {} — קבוצה בלי איברים; הסימן אינו Φ
  • בדפי הקורס הסימנים מודפסים כאותיות מודגשות N, R, Z

מושגים שכבר למדתם בקורס: 0. שיעורים שהושלמו: 0.
