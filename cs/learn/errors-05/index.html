משמעות לכל קלט? ALEF, GIMEL, HE

מוצאים בדיוק לאילו קלטים יש פלט

מקור:שקף 5 "דוגמה 1" (ALEF, שתי טבלאות מעקב — באחת פצצה אדומה ו־X אדום), שקף 14 "דוגמה 3" (GIMEL), שקף 18 "דוגמה 5" (HE). במדריך המעובד הפרוצדורה נקראת "HEI"; בצילום כתוב HE.· ודאות בפענוח המקור: גבוהה
המורה שלך

אהקדמה

מה לומדים

ננתח שלוש פרוצדורות מהשקפים ונשאל על כל אחת: לאילו קלטים יש לה משמעות?

למה זה חשוב

זו שאלה טיפוסית במבחן. כדי לענות צריך לחבר את כל מה שלמדנו: לעקוב, לחפש SUB ממונה ריק, ולחפש לולאה שלא נגמרת.

בסוף השיעור תדעו
  • למצוא את התנאי המדויק שבו ל־ALEF יש משמעות (B≥AB \geq AB≥A)
  • להסביר למה ל־GIMEL יש משמעות לכל קלט
  • להסביר למה ל־HE אין משמעות כש־A ≠ 0 — ואיזו תקלה מגיעה קודם: אינסופיות או חיסור ממונה ריק

במילון מושגים

משמעות לכל קלט

לכל ערכי ההתחלה האפשריים הריצה מגיעה לסוף ונותנת פלט.

תנאי למשמעות

משפט שמתאר בדיוק לאילו קלטים יש פלט, למשל "B גדול או שווה ל־A".

פצצה בטבלת המעקב

הציור שהמרצה שם במשבצת שבה הריצה "מתפוצצת": שם מתבצע SUB ממונה ריק.

X אדום על עמודת הפלט

הסימן של המרצה ל"אין פלט": לריצה הזו אין משמעות.

לולאה מקוננת

לולאה בתוך לולאה. ב־HE יש WHILE (A) בתוך WHILE (A).

גהסבר ויזואלי

רמה: רגילהסבר חדש

ALEF (דוגמה 1): בכל סיבוב SUB (B) ו־SUB (A). יש בדיוק A סיבובים, ובכל אחד יוצא כדור מ־B. לכן B צריך לפחות A כדורים: יש משמעות כש־B≥AB \geq AB≥A, והפלט A=0,  B=B−AA = 0,\; B = B - AA=0,B=B−A. אחרת — חיסור ממונה ריק.

GIMEL (דוגמה 3): כל SUB נמצאת בתוך WHILE על אותו מונה, וכל לולאה מקטינה את המונה שלה. אין חיסור מריק ואין אינסופיות: "יש משמעות לכל קלט". הפלט: A מקבל את הערך של B, ו־B מתרוקן.

HE (דוגמה 5): A = 0 — הלולאה החיצונית לא מתחילה, יש משמעות. A ≠ 0 — הלולאה הפנימית בודקת את A אבל לא משנה אותו, ובכל סיבוב מוציאה כדור מ־B. B נגמר — חיסור ממונה ריק.

חומר מקור

דוגמה 1: @ALEF(A,B) / 1. WHILE (A) / 2. SUB (B) / 3. SUB (A) / 4. ENDW

חומר מקור

טבלה עליונה (A = 3, B = 10): אחרי שלושה סיבובים הפלט A = 0, B = 7.

טבלה תחתונה (A = 6, B = 2): אחרי סיבוב 2 — A = 4, B = 0. בסיבוב 3, בשורה 2, מצוירת פצצה אדומה, ועל עמודת הפלט X אדום גדול.

חומר מקור

דוגמה 3: @ GIMEL (A,B) / 1. WHILE (A) / 2. SUB (A) / 3. ENDW / 4. WHILE (B) / 5. ADD (A) / 6. SUB (B) / 7. ENDW — "יש משמעות לכל קלט".

חומר מקור

דוגמה 5: @HE(A,B) / 1. WHILE (A) / 2. WHILE (A) / 3. SUB (B) / 4. ENDW / 5. ENDW

A ≠ 0 – יבוצע חיסור ממונה ריק, לפרוצדורה אין משמעות.

A = 0 – לפרוצדורה יש משמעות.

ההתנסות

זה גוף ALEF. בדקו את הכלל B≥AB \geq AB≥A: הריצו עם A = 3, B = 3, ואחר כך עם A = 4, B = 3.

אחר כך הוסיפו שורה אחת כך שלפרוצדורה תהיה משמעות לכל קלט, ו־B יחזור בסוף לערך ההתחלתי שלו. (מה אם בכל סיבוב נוסיף כדור ל־B רגע לפני שמוציאים ממנו?)

ושאלה לבדיקת ההבנה

חסיכום והמשך

מה למדנו
  • ALEF: יש משמעות בדיוק כש־B≥AB \geq AB≥A; אז הפלט A=0,  B=B−AA = 0,\; B = B - AA=0,B=B−A.
  • GIMEL: יש משמעות לכל קלט; הפלט: A = הערך ההתחלתי של B, ו־B = 0.
  • HE: A = 0 — יש משמעות; A ≠ 0 — חיסור ממונה ריק (B נגמר לפני שהאינסוף "מספיק" לקרות).
  • השיטה: בודקים כל SUB (מתי המונה שלה ריק?) וכל WHILE (האם המונה שלה מתקרב ל־0?), ומחלקים למקרים.

מושגים שכבר למדתם בקורס: 0. שיעורים שהושלמו: 0.

מה הלאה

בשיעור הבא נסכם את שני סוגי חוסר המשמעות בטבלה של המרצה — "פשע, חשוד, אליבי" — ונשתמש בה כרשימת בדיקה מהירה לכל תוכנית.
