המורה שלך

אהקדמה

מה לומדים

נלמד מהי קבוצה, מהם איברי הקבוצה, ושלוש דרכים לכתוב קבוצה: רשימה מלאה, רשימה חלקית עם שלוש נקודות, וכלל.

למה זה חשוב

קבוצות הן שפה שמשתמשים בה לאורך כל הקורס. בדף הקריאה כתוב שהסעיף "מכיל ידע שלו נזקקים בפרקים העיקריים בקורס". כדי לדבר על קבוצות, צריך קודם לדעת לכתוב אותן.

בסוף השיעור תדעו
  • להסביר במילים פשוטות מהי קבוצה ומהו איבר
  • לכתוב קבוצה קטנה כרשימה בתוך סוגריים מסולסלים
  • לדעת שאין משמעות לסדר האיברים בקבוצה
  • לקרוא כלל כמו {x∣5≤x<50}\{x \mid 5 \le x < 50\}{x∣5≤x<50}: "x כך ש־..."

במילון מושגים

קבוצה

אוסף של דברים — כמו קופסה שיש בה חפצים. מה שבתוך הקופסה שייך לקבוצה.

איבר

כל דבר אחד שנמצא בקבוצה. בקבוצה {8,0,19,45}\{8, 0, 19, 45\}{8,0,19,45} יש ארבעה איברים: 8, 0, 19 ו־45.

סוגריים מסולסלים

הסימנים { ו־}. בתוכם כותבים את איברי הקבוצה, עם פסיק בין איבר לאיבר.

שלוש נקודות

פירושן "וכן הלאה": ממשיכים לפי אותה חוקיות. למשל {1,3,5,7,…}\{1, 3, 5, 7, \ldots\}{1,3,5,7,…}.

כלל (תנאי)

משפט שבודקים מול כל מספר: מי שעומד בו — בפנים, ומי שלא — בחוץ.

גהסבר ויזואלי

רמה: רגילהסבר חדש

דרך (א) — רשימה מלאה: כותבים את כל האיברים בתוך סוגריים מסולסלים: A={8,0,19,45}A = \{8, 0, 19, 45\}A={8,0,19,45}.

אין משמעות לסדר: {8,0,19,45}={8,45,0,19}\{8, 0, 19, 45\} = \{8, 45, 0, 19\}{8,0,19,45}={8,45,0,19}.

רשימה מתאימה רק לקבוצה סופית. את קבוצת כל השלמים הגדולים מ־100 אי אפשר לרשום כך, כי אין לה סוף.

דרך (ב) — דוגמאות ושלוש נקודות: C={1,3,5,7,…}C = \{1, 3, 5, 7, \ldots\}C={1,3,5,7,…} היא קבוצת כל המספרים האי־זוגיים החיוביים.

דרך (ג) — כלל: E={x∣5≤x<50}E = \{x \mid 5 \le x < 50\}E={x∣5≤x<50}. קוראים: "x כך ש־x בין 5 (כולל) ל־50 (לא כולל)".

חומר מקור

"סעיף זה אינו קשור לשאר סעיפי הפרק, אך הוא מכיל ידע שלו נזקקים בפרקים העיקריים בקורס, והצצה לרעיונות חשובים שילוו אותנו לאורך הקורס."

חומר מקור

קבוצה היא אוסף של עצמים כלשהם. העצמים הנמצאים בקבוצה הם איברי הקבוצה. נהוג לסמן קבוצה באות רישית (Capital Letter) מודגשת, למשל A.

חומר מקור

דרך (א): נפרט את כל איבריה בתוך סוגריים מסולסלים. דוגמה: A={8,0,19,45}A = \{8, 0, 19, 45\}A={8,0,19,45}. אין משמעות לסדר האיברים המוזכרים בקבוצה, ולכן: A={8,0,19,45}={8,45,0,19}A = \{8, 0, 19, 45\} = \{8, 45, 0, 19\}A={8,0,19,45}={8,45,0,19}. הקבוצה B, שהיא קבוצת כל הספרות על קוביית משחק, תיראה כך: B={1,2,3,4,5,6}B = \{1,2,3,4,5,6\}B={1,2,3,4,5,6}.

חומר מקור

לתאר כך את קבוצת כל המספרים השלמים והחיוביים הקטנים מ־100 — "המשימה תהיה מעיקה אך אפשרית". את קבוצת כל המספרים השלמים הגדולים מ־100 — "לא נוכל לעשות כן, כי מספר האיברים בקבוצה הזו אינו סופי".

חומר מקור

דרך (ב): נספק רצף של דוגמאות שאפשר להסיק מהן מהם כל איברי הקבוצה, ונוסיף שלוש נקודות. דוגמה: C={1,3,5,7,…}C = \{1, 3, 5, 7, \ldots\}C={1,3,5,7,…} — קבוצת כל המספרים האי־זוגיים החיוביים. שלוש הנקודות יכולות להופיע במקומות שונים, למשל המספרים המתחלקים בשלוש: {…,−9,−6,−3,0,3,6,9,…}\{\ldots, -9, -6, -3, 0, 3, 6, 9, \ldots\}{…,−9,−6,−3,0,3,6,9,…}.

חומר מקור

דרך (ג): נספק כלל אותו מקיימים כל חברי הקבוצה. דוגמה: E={x∣5≤x<50}E = \{x \mid 5 \le x < 50\}E={x∣5≤x<50}. נקרא את הכלל משמאל לימין: "x כך ש־x בין 5 (כולל) ל־50 (לא כולל)". כדי שיובהר שמדובר במספרים שלמים, יש לתקן: E = {x | 5≤x<50 וכן x מספר שלם}.

חומר מקור

דרך (א) תשמש לתיאור קבוצות שבהן מספר קטן של איברים, כגון {0,1}\{0,1\}{0,1}. בשאר המקרים נשתמש בדרך (ג). שלוש נקודות אינן חלק מהשפה המתמטית, ונימנע מביטויים כאלה.
