איפוס מונה והכנסת מספר קבוע

דוגמאות 4–5: "אפס את R2", ואז "הכנס 3 למונה R2"

מקור:דוגמאות 4–5 במצגת "פעולות ראשונות" (שקפים 9–10)· ודאות בפענוח המקור: גבוהה
המורה שלך

אהקדמה

מה לומדים

שני כלים שנשתמש בהם כל הזמן: איפוס מונה (לרוקן אותו לגמרי), והכנסת מספר קבוע למונה — למשל, שיהיו בו בדיוק 3 כדורים.

למה זה חשוב

ADD מוסיפה למה שכבר יש. אבל לפעמים צריך ערך מסוים, בלי קשר למה שהיה קודם. הדרך: קודם לאפס, ואז להוסיף.

בסוף השיעור תדעו
  • לכתוב לולאת איפוס: WHILE (X) / SUB (X) / ENDW
  • להכניס מספר קבוע: איפוס, ואחריו כמה ADD
  • להבחין בין "הוסף 3" ל"הכנס 3"

במילון מושגים

איפוס

לרוקן מונה, כך שיהיה בו 0.

הכנסת מספר

לדאוג שבמונה יהיה בדיוק מספר מסוים — למשל 3 — בלי קשר למה שהיה בו קודם.

"הוסף" מול "הכנס"

"הוסף 3" — עוד שלושה כדורים על מה שיש. "הכנס 3" — בסוף יהיו בדיוק שלושה.

קבוע

מספר שכתוב בתוכנית עצמה ולא תלוי בקלט — כמו ה־3 בדוגמה 5.

גהסבר ויזואלי

רמה: רגילהסבר חדש

דוגמה 4 של המרצה: WHILE (R2) / SUB (R2) / ENDW — "אפס את R2".

הלולאה בודקת את R2 ומוציאה כדור מ־R2. לכן היא נגמרת בדיוק כשהוא מתרוקן — ובלי שגיאה: SUB מתבצעת רק אחרי בדיקה שמצאה כדור.

דוגמה 5: אחרי האיפוס באות שלוש שורות ADD (R2) — וכל התוכנית יחד היא "הכנס 3 למונה R2". מה שהיה ב־R2 קודם כבר לא משנה.

חומר מקור

דוגמה 4 — איפוס מונה (שקף 9): WHILE (R2) / SUB (R2) / ENDW, ולידה תווית אחת: "אפס את R2".

חומר מקור

דוגמה 5 — החלפת ערך מונה במספר מסויים (למשל, 3) (שקף 10): קודם "אפס את R2" (הלולאה), אחר כך "הוסף 3 ל-R2" (שלוש שורות ADD (R2)), וכל התוכנית יחד: "הכנס 3 למונה R2".

דהדגמה מפורקתהסבר חדש

בדיקה: R2 = 2, כלומר אינו ריק — נכנסים ללולאה.

R2 = 2

ההתנסות

הריצו עם R2 = 9, ואחר כך עם R2 = 0 ועם R2 = 20. מה יוצא בכל פעם?

ואז עמדו ביעד: שנו את התוכנית כך שתכניס 5 ל־R2.

חסיכום והמשך

מה למדנו
  • איפוס: WHILE (X) / SUB (X) / ENDW — בטוח לכל ערך, גם 0
  • הכנסת קבוע = איפוס, ואחריו ADD כמספר הרצוי
  • "הוסף 3" תלוי במה שהיה; "הכנס 3" תמיד נותן 3

מושגים שכבר למדתם בקורס: 0. שיעורים שהושלמו: 0.

מה הלאה
