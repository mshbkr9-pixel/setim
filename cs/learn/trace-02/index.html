נוסחה אחרי n סיבובים

עמודה כללית "סיבוב n" ומציאת הסיבוב האחרון

מקור:שקף 14 במצגת "טבלאות מעקב" (גרסה 3); נוהל העבודה בעמ' 11 של המחברת המסכמת· ודאות בפענוח המקור: גבוהה
המורה שלך

אהקדמה

מה לומדים

נלמד לכתוב עמודה אחת כללית, "סיבוב n", שמתארת כל סיבוב שהוא — ואז למצוא מתי הלולאה נגמרת בעזרת משוואה קטנה.

למה זה חשוב

עם R1 = 65 יש 65 סיבובים. לכתוב 65 עמודות זה ארוך ומועד לטעויות. עמודה כללית אחת חוסכת את כל העבודה.

בסוף השיעור תדעו
  • למצוא בכמה כל מונה משתנה בסיבוב אחד
  • לכתוב את ערכי המונים אחרי סיבוב n (למשל 65−n65 - n65−n ו־10+n10 + n10+n)
  • למצוא את הסיבוב האחרון ואת ערכי הפלט

במילון מושגים

n

אות שמייצגת "מספר סיבוב כלשהו". אם n = 3 — מדברים על הסיבוב השלישי.

ביטוי

חישוב שכתוב עם אותיות ומספרים, כמו 65−n65 - n65−n. כשמציבים מספר במקום n מקבלים ערך.

שינוי בסיבוב

בכמה מונה גדל או קטן בסיבוב אחד. בדוגמה של המרצה: R1 קטן ב־1 ו־R2 גדל ב־1.

סיבוב אחרון

הסיבוב שבסופו מונה הבקרה מתרוקן. אחריו הבדיקה של WHILE מוציאה אותנו מהלולאה.

מונה הבקרה

המונה שבסוגריים של WHILE. הוא קובע מתי הלולאה נעצרת.

גהסבר ויזואלי

רמה: רגילהסבר חדש

בשקף 14 המרצה לוקחת את אותו קוד עם קלט R1 = 65, R2 = 10:

  • אחרי סיבוב 1: R1 = 64, R2 = 11.
  • אחרי סיבוב 2: R1 = 63, R2 = 12.
  • רואים חוק: בכל סיבוב R1 יורד ב־1 ו־R2 עולה ב־1.
  • לכן אחרי n סיבובים: R1 = 65 − n, R2 = 10 + n.

הלולאה נגמרת כש־R1 = 0. פותרים 0=65−n0 = 65 - n0=65−n ומקבלים n=65n = 65n=65. מציבים: R2 = 10 + 65 = 75.

חומר מקור

גרסה 3 (שקף 14) — עמודות הטבלה:

  • קלט: R1 = 65, R2 = 10
  • סיבוב 1 (ש' 2–3): 64, 11
  • סיבוב 2 (ש' 2–3): 63, 12
  • סיבוב n (ש' 2–3): 65-n, 10+n
  • סיבוב אחרון, n=65: 0, 75
חומר מקור

בשורה של R1 מצויר סימן "=" ירוק בין 0 לבין 65-n, ומתחת לטבלה מסגרת עם החישוב:

0 = 65 − n /+n

n = 65

4ENDW

ההתנסות

עכשיו תורכם. לפני שמריצים, חשבו בעזרת עמודה כללית: מה יהיה בסוף עבור R1 = 40, R2 = 7? (אחרי n סיבובים: R1 = 40 − n, R2 = 7 + n.) שנו את ערכי הקלט ל־40 ו־7, הריצו ובדקו (הכפתור "עד הסוף" מדלג על כל הסיבובים). נסו גם מספרים משלכם.

ושאלה לבדיקת ההבנה

חיזוי פלטרמה 2תרגיל חדש

בקוד הזה, בכל סיבוב A יורד ב־1 ו־B עולה ב־2. הקלט: A = 50, B = 1. בעזרת עמודה כללית "סיבוב n" — מה יהיו ערכי הפלט?

1WHILE (A)
2   ADD (B)
3   ADD (B)
4   SUB (A)
5ENDW

ערכי התחלה: A=50, B=1

חסיכום והמשך

מה למדנו
  • מוצאים את השינוי בסיבוב אחד, וממנו כותבים עמודה כללית "סיבוב n"
  • את הסיבוב האחרון מוצאים מהמשוואה "מונה הבקרה = 0" (למשל 0=65−n0 = 65 - n0=65−n)
  • מציבים את n בעמודה הכללית ומקבלים את הפלט בלי לכתוב את כל הסיבובים

מושגים שכבר למדתם בקורס: 0. שיעורים שהושלמו: 0.
