MOVE (A,B): העתקה ששומרת על המקור

שני משתנים, מונה עזר C, וסדר המונים בקריאה

מקור:דוגמה 7 במצגת "פרוצדורות ומשתנים" (שקף 15; צילומים 26 ו־27 הם אותו שקף). במצגת היא באה אחרי HUN (שקף 14), שנלמד בשיעור הבא.· ודאות בפענוח המקור: גבוהה
המורה שלך

אהקדמה

מה לומדים

נכיר את MOVE: פרוצדורה עם שני משתנים, שמעתיקה את A אל B ומשאירה את A כמו שהיה. בפנים היא משתמשת במונה עזר C.

למה זה חשוב

זה הטריק של דוגמה 7 (העתקה עם מונה עזר) — אבל עכשיו כמילה אחת בשפה. כותבים MOVE (R1,R2) במקום 15 שורות.

בסוף השיעור תדעו
  • לקרוא כותרת עם שני משתנים: @ MOVE(A,B)
  • לדעת איזה מונה בקריאה מחליף את A ואיזה את B — ולמה הסדר קובע את הכיוון
  • להבין את התפקיד של מונה העזר C, ואת מה שהקורס לא אומר עליו

במילון מושגים

שני משתנים

פרוצדורה יכולה לקבל כמה מונים. בכותרת @ MOVE(A,B) יש שניים, מופרדים בפסיק.

סדר המונים בקריאה

ב־MOVE (R1,R2) המונה הראשון מחליף את A והשני את B. אם מחליפים את הסדר — מחליפים את כיוון ההעתקה.

מונה עזר פרטי

בסימולטור (ברירת מחדל): לכל קריאה יש מונה עזר משלה, שמתחיל ב־0 ונעלם בסוף.

מונה עזר משותף

האפשרות השנייה בסימולטור: מונה העזר הוא המונה בעל אותו שם בתוכנית הקוראת.

גהסבר ויזואלי

רמה: רגילהסבר חדש

הכותרת @ MOVE(A,B) מגדירה שני משתנים, מופרדים בפסיק. בקריאה המונים מוחלפים לפי הסדר: ב־MOVE (R1,R2) — A ← R1, B ← R2; ב־MOVE (R2,R1) — להפך.

הגוף:

  • ZERO (B) ו־ZERO (C): מאפסים את היעד ואת מונה העזר
  • לולאה ראשונה: כל כדור של A עובר גם ל־B וגם ל־C (A מתרוקן)
  • לולאה שנייה: C חוזר אל A (C מתרוקן)

בסוף: B = A, ו־A כמו בהתחלה.

חומר מקור

דוגמה 7 (שקף 15): @ MOVE(A,B) / ZERO (B) / ZERO (C) / WHILE (A) / ADD(B) / ADD (C) / SUB (A) / ENDW / WHILE (C) / ADD(A) / SUB (C) / ENDW. המונה C משמש בגוף, אף שאינו מופיע בכותרת.

חומר מקור

בדף הקריאה של פרק ב.1 המרצה כותב: "בפרק הקודם הגדרנו את המילה MOVE ופירשנו את האלגוריתם", ומציג את MOVE בטבלת תוויות. התווית הראשית שם: "העתק את A ל-B תוך איפוס C". בגרסה שבדף הקריאה האיפוס כתוב בלולאות (WHILE (B) / SUB (B) / ENDW) במקום ZERO (B).

ההתנסות

ל־C של התוכנית שלנו יש 7 כדורים. הריצו ובדקו: מה קרה ל־R1, ל־R2 ול־C? פתחו את חלון המסגרות — ל־MOVE יש C משלה.

אחר כך החליפו ל־MOVE (R2,R1) והריצו שוב: לאיזה כיוון ההעתקה עכשיו?

חסיכום והמשך

מה למדנו
  • MOVE (A,B) מעתיקה את A אל B ושומרת על A — דוגמה 7, כמילה אחת
  • בקריאה, המונים מוחלפים לפי הסדר: הראשון ← A, השני ← B
  • C הוא מונה עזר. החומר לא אומר מה קורה ל־C של התוכנית הקוראת; בסימולטור ברירת המחדל: פרטי
