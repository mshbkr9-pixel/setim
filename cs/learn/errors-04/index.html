לולאה אינסופית: BET

ריצה ארוכה מול ריצה שהוכח שהיא אינסופית

מקור:שקף 9, "דוגמה 2" (הפרוצדורה BET) עם שתי טבלאות מעקב; התיבה "אינסופיות ואי-סבירות בזמן" — שקף 2. האופן שבו הסימולטור מוכיח אינסופיות הוא של האתר, לא של המרצה.· ודאות בפענוח המקור: גבוהה
המורה שלך

אהקדמה

מה לומדים

נכיר את הסוג השני של חוסר משמעות: אינסופיות — לולאה שלא נגמרת לעולם. נראה אותה בדוגמה 2 של המרצה, הפרוצדורה BET.

למה זה חשוב

לולאה אינסופית לא נותנת שום פלט — מחכים לנצח. וחשוב לא פחות: ללמוד לא לקרוא "אינסופית" לכל ריצה שפשוט לוקחת הרבה זמן.

בסוף השיעור תדעו
  • להסביר למה WHILE (A) לא נגמרת כש־A רק גדל
  • לקרוא טבלת מעקב לפי סיבובים, כולל העמודה "סיבוב n"
  • להבחין בין "הריצה ארוכה" לבין "הוכח שהריצה אינסופית"

במילון מושגים

לולאה אינסופית

לולאה שהבדיקה שלה אף פעם לא מוצאת את המונה ריק — ולכן היא חוזרת שוב ושוב בלי סוף.

סיבוב n

סיבוב כללי — "הסיבוב ה־n". כותבים בו נוסחה במקום מספר, וכך מתארים כל סיבוב בבת אחת.

מגבלת צעדים

מספר הצעדים המרבי שהסימולטור מוכן לבצע. כשמגיעים אליו הוא עוצר — אבל זה לא אומר שהריצה אינסופית.

הוכחה של אינסופיות

הסבר שמראה שהמונה שה־WHILE בודק לעולם לא יתרוקן. רק עם הסבר כזה מותר לומר "הלולאה אינסופית".

אי-סבירות בזמן

ריצה שאורכת זמן לא סביר. בשקף היא מופיעה באותה תיבה עם אינסופיות, בלי הסבר נוסף.

גהסבר ויזואלי

רמה: רגילהסבר חדש

ב־BET, בכל סיבוב: ADD (B) ו־ADD (A). A גדל בכל סיבוב, ושום שורה לא מקטינה אותו.

  • אם A = 0 בהתחלה: הבדיקה מוצאת את A ריק, מדלגים על הלולאה, ויש פלט.
  • אם A ≠ 0: A רק גדל — 3, 4, 5, … — והבדיקה תמיד מוצאת אותו לא ריק. הלולאה לא נגמרת, ואין פלט.

ריצה ארוכה אינה ריצה אינסופית. לולאה שמוציאה מיליון כדורים, אחד בכל סיבוב, אורכת המון צעדים — אבל היא נגמרת. כדי לומר "אינסופית" צריך להראות שהמונה הנבדק לעולם לא יתרוקן.

חומר מקור

דוגמה 2: @BET(A,B) / 1. WHILE (A) / 2. ADD (B) / 3. ADD (A) / 4. ENDW

חומר מקור

טבלה עליונה: קלט A = 0, B = 8; פלט A = 0, B = 8.

חומר מקור

טבלה תחתונה: קלט A = 2, B = 13. סיבוב 1 (שורות 2+3): A = 3, B = 14. סיבוב 2: A = 4, B = 15. סיבוב n: A = n+2, B = n+13. על עמודת הפלט מצויר X אדום גדול.

ההתנסות

נסו כמה ניסויים:

  • הריצו עם A = 0, ואחר כך עם A = 1. מה ההבדל?
  • שנו את שורה 3 ל־SUB (A). האם הלולאה נגמרת עכשיו? מה יהיה B בסוף?
  • כתבו לולאה WHILE (A) שבגוף שלה רק ADD (B) ו־SUB (B). האם A משתנה? מה מכריז הסימולטור?

ושאלה לבדיקת ההבנה

בחירהרמה 2תרגיל חדש

הסימולטור עצר ריצה של תוכנית והודיע שהריצה לא הסתיימה במסגרת מגבלת הצעדים. מה אפשר להסיק?

חסיכום והמשך

מה למדנו
  • WHILE (X) נגמרת רק כש־X מתרוקן. אם בתוך הלולאה X רק גדל (או לא משתנה) — היא אינסופית.
  • BET: A = 0 – יש פלט (בלי שינוי); A ≠ 0 – לולאה אינסופית, אין פלט.
  • סיבוב n: A = n + 2, B = n + 13 — נוסחה שמראה ש־A לעולם לא יתרוקן.
  • ריצה ארוכה ≠ ריצה אינסופית. מגבלת צעדים אינה הוכחה.

מושגים שכבר למדתם בקורס: 0. שיעורים שהושלמו: 0.
