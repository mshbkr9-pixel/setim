אהקדמה

מה לומדים

נלמד שהגדרה מלאה של פונקציה כוללת שלושה חלקים: תחום, טווח וכלל התאמה. נכיר גם את הכתיב המקובל f:A→Bf : A \to Bf:A→B.

למה זה חשוב

אותו כלל — למשל "מעלים בריבוע" — יכול להגדיר כמה פונקציות שונות. בלי תחום וטווח לא ברור אילו שאלות מותר לשאול, ואילו תשובות מותר לתת.

בסוף השיעור תדעו
  • להסביר מהו כלל התאמה ולחשב בעזרתו ערך, כמו f(3)=9f(3) = 9f(3)=9
  • לכתוב ולקרוא הגדרה מלאה, כמו f2:N→N, f2(a)=a2f_2 : \mathbb{N} \to \mathbb{N},\ f_2(a) = a^2f2​:N→N, f2​(a)=a2
  • להבין למה g2(7.5)g_2(7.5)g2​(7.5) היא שאלה שלא מתקבלת
  • לדעת שפונקציה לא חייבת להחזיר את כל המספרים שבטווח

במילון מושגים

כלל התאמה

המתכון שמחשב את התשובה לכל שאלה. למשל: "מעלים את המספר בריבוע".

ערך הפונקציה — f(3)

התשובה ש־fff נותנת לשאלה 3. קוראים: "f של 3". אם f(a)=a2f(a) = a^2f(a)=a2, אז f(3)=9f(3) = 9f(3)=9.

תחום

כל השאלות שמותר לשאול את הפונקציה. בגרף — ציר ה־x.

טווח

כל התשובות שמותר לפונקציה לתת. בגרף — ציר ה־y.

ℕ — המספרים הטבעיים

0, 1, 2, 3 וכן הלאה: מספרים שלמים שאינם שליליים. בקורס הזה 0 הוא מספר טבעי.

ℝ — המספרים הממשיים

כל המספרים שעל ציר המספרים: שלמים, שברים כמו 7.5, מספרים שליליים, וגם 2\sqrt{2}2​ ו־π\piπ.

גהסבר ויזואלי

רמה: רגילהסבר חדש

הכלל f(a)=a2f(a) = a^2f(a)=a2 מאפשר לחשב: f(3)=9f(3) = 9f(3)=9. בדף הקריאה: "כששואלים את f את השאלה 3 מקבלים את התשובה 9".

אבל כלל לבד אינו פונקציה. בדף מוצגים שני כללים בלבד — וארבע פונקציות שונות:

  • f1:R→R, f1(a)=a2f_1 : \mathbb{R} \to \mathbb{R},\ f_1(a) = a^2f1​:R→R, f1​(a)=a2 — f הרציפה
  • f2:N→N, f2(a)=a2f_2 : \mathbb{N} \to \mathbb{N},\ f_2(a) = a^2f2​:N→N, f2​(a)=a2 — f הבדידה
  • g1:R→R, g1(a)=ag_1 : \mathbb{R} \to \mathbb{R},\ g_1(a) = ag1​:R→R, g1​(a)=a — g הרציפה
  • g2:N→N, g2(a)=ag_2 : \mathbb{N} \to \mathbb{N},\ g_2(a) = ag2​:N→N, g2​(a)=a — g הבדידה

לכן הגדרה מלאה של פונקציה כוללת תחום, טווח וכלל התאמה.

חומר מקור

בעמוד קודם הצגנו שני כללי התאמה: f(a)=a2f(a) = a^2f(a)=a2 ו־g(a)=ag(a) = ag(a)=a, אך ראינו גרפים של 4 פונקציות שונות: f הרציפה, שעוסקת בכל המספרים הממשיים; f הבדידה, שעוסקת אך ורק במספרים טבעיים; g הרציפה; g הבדידה.

חומר מקור

"הפונקציה 1 שונה מהפונקציה 2 ממש כשם שהפונקציה 1 שונה מהפונקציה 3 או מהפונקציה 4. מכאן, שכלל ההתאמה אינו מספיק כדי להגדיר פונקציה מסויימת באופן מדוייק, שהרי לשתי פונקציות שונות יכול להיות אותו כלל התאמה. מסיבה זו, הגדרה פורמאלית מלאה של פונקציה תכלול תחום וטווח, נוסף לכלל ההתאמה."

חומר מקור

התחום הוא ציר ה־x, קבוצת הקלטים של הפונקציה, "השאלות שמותר לשאול את הפונקציה". הטווח הוא ציר ה־y, קבוצת הפלטים של הפונקציה, "התשובות שמותר לפונקציה להשיב". המוסכמה: שם הפונקציה : תחום → טווח, וקוראים "מ־[תחום] ל־[טווח]".
