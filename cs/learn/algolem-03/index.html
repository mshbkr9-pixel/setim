לולאת WHILE

לחזור על פעולות כל עוד מונה הבקרה אינו ריק

מקור:שקף "לולאה בשפת אלגולם" ודוגמאות 1–2 מהמצגת "פעולות ראשונות"· ודאות בפענוח המקור: גבוהה
המורה שלך

אהקדמה

מה לומדים

נלמד את ההוראה השלישית והאחרונה של אלגולם: לולאה. היא מאפשרת לחזור על אותן פעולות שוב ושוב.

למה זה חשוב

עם ADD ו־SUB לבד אפשר לשנות מונה רק בכדור אחד לכל שורה. לולאה מאפשרת לכתוב תוכנית קצרה שעובדת על כל כמות של כדורים — 5 או 5,000.

בסוף השיעור תדעו
  • לקרוא לולאת WHILE ... ENDW ולהבין מתי נכנסים אליה ומתי יוצאים ממנה
  • לספור כמה סיבובים תבצע לולאה
  • לדעת מה יהיו ערכי המונים בסוף הלולאה

במילון מושגים

לולאה

קבוצת הוראות שחוזרים עליה שוב ושוב, כמו להקיף מסלול ריצה כמה פעמים.

מונה הבקרה

המונה שכתוב בסוגריים אחרי WHILE. לפי מה שיש בו מחליטים אם להמשיך.

גוף הלולאה

השורות שבין WHILE (...) לבין ENDW — מה שעושים בכל סיבוב.

סיבוב

פעם אחת שבה מבצעים את כל גוף הלולאה מההתחלה ועד הסוף.

ENDW

סימן הסוף של הלולאה (END WHILE). כשמגיעים אליו חוזרים למעלה לבדוק שוב.

גהסבר ויזואלי

רמה: רגילהסבר חדש

WHILE (X) בודקת את המונה X. אם הוא אינו ריק — מבצעים את גוף הלולאה עד ENDW, ואז חוזרים לבדיקה.

אם X ריק — קופצים אל אחרי ENDW וממשיכים משם.

הבדיקה מתבצעת לפני כל סיבוב, ולכן אם X ריק כבר מההתחלה — הלולאה לא מתבצעת אף פעם.

חומר מקור

לולאה בשפת אלגולם: חזור על גוף הלולאה, כל עוד מונה הבקרה RxR_xRx​ אינו ריק.

חומר מקור

דוגמה 2 — הוספת תוכן מונה אחד למונה אחר: WHILE (R1) / ADD (R2) (הוסף 1 ל־R2) / SUB (R1) (הורד 1 מ־R1) / ENDW.

דהדגמה מפורקתהסבר חדש

מעקב אחרי WHILE (R1) ADD (R2) SUB (R1) ENDW עם R1 = 2, R2 = 0

שלב 1 מתוך 6
1WHILE (R1)
2   ADD (R2)
3   SUB (R1)
4ENDW

בדיקה: R1 = 2, כלומר אינו ריק — נכנסים לסיבוב 1.

R1 = 2R2 = 0

ההתנסות

שנו את ערכי ההתחלה (למשל R1 = 0, או R1 = 7) והריצו. כמה סיבובים יהיו? מה קורה כש־R1 ריק מההתחלה? נסו גם להוסיף שורה ADD (R2) שנייה בתוך הלולאה.

ושאלה לבדיקת ההבנה

חיזוי פלטרמה 1תרגיל חדש

מה יהיו ערכי המונים בסוף הריצה?

1WHILE (R1)
2   ADD (R2)
3   SUB (R1)
4ENDW

ערכי התחלה: R1=3, R2=4

חסיכום והמשך

מה למדנו
  • WHILE (X) ... ENDW חוזרת על הגוף כל עוד X אינו ריק
  • הבדיקה נעשית לפני כל סיבוב — אם X ריק מההתחלה, אין אף סיבוב
  • כשכל סיבוב מוציא כדור אחד ממונה הבקרה, מספר הסיבובים = ערכו בכניסה ללולאה

מושגים שכבר למדתם בקורס: 0. שיעורים שהושלמו: 0.

מה הלאה

בשיעור הבא נשתמש בלולאה כדי להעביר את כל התוכן של מונה אחד למונה אחר — ונראה מה קורה למונה המקורי.
