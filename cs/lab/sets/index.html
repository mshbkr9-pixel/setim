תורת הקבוצות

גררו איברים בין הקבוצות וראו את הסימון המתמטי משתנה: שייכות (∈), הכלה (⊆), שוויון, הפרש (A − B, בכתיב הקורס), קבוצה ריקה וזוגות סדורים.

כתבו איברים מופרדים בפסיקים (עד 18 איברים בתמונה).
A = {1, 2, 3, 4, 5}
B = {1, 3, 5, 7, 9}
A − B = {2, 4}
B − A = {7, 9}
גררו איבר לאזור אחר (או לחצו עליו ובחרו לאן). לחיצה על איבר מראה את השייכות שלו.
A − B: כל מה שב־A ואינו ב־B.

הגדרת קבוצה באמצעות תנאי

E = { x ∈ ℤ |x}

E = {5, 6, 7, 8, 9, 10, 11}

לחצו על הסימנים כדי להחליף בין < ל־≤ וראו אילו מספרים נכנסים או יוצאים.
